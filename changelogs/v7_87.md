# Deidril's Pathfinder 2 PDF Import v7.87
For *foundry V14* AND *pf2e system v8.2.0+*

**Support for Foundry v14**
- All scenes templates have been externalized into the module datas/imports directory. 
- Scenes are no longer embed into the module code, but are modifiable by everyone, and can be resubmitted as PR for an upgrade (sections, lights, better walls, whatever ...), or dropped into the contributions channel of the module's discord
- All scenes have been fixed to use the foundry v14 format (was quite long to do)

**Minor fixes**
- fixed or added links to journal entries on scenes for : q20, q27
- some journal sections didn't have the right symbol in : a few more flowers, 

**Support for forge**
The problem with executions of the module on forge came from the use of external sources for token rings.
I solved it by coming back to simple colored token rings, in waiting i find a better option.
Therefore, the module works again on forge
